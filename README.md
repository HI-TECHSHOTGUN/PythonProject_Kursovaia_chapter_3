# Приложение для анализа банковских операций
## Описание
Приложение анализирует транзакции, которые находятся в Excel-файле. Приложение генерирует JSON-данные для веб-страниц, форматирует Excel-отчеты, а также предоставлять другие сервисы.

## Установка
1. **Клонируйте репозиторий**
        [клик](https://github.com/HI-TECHSHOTGUN/Python_project_HW.git)
## Зависимости и виртуальное окружение:
1. **Виртуальное окружение** (в данном случае Poetry) установки не требует и идёт в комплекте при клонировании репозитория.
2. **Зависимости** также можно посмотреть в этом файле [клик](pyproject.toml)

## Функционал проекта:
1. **Главная** выводит для веб-страницы JSON-ответ, где указаны данные карт, топ транзакций и данные с биржи
2. **Простой поиск** реализован поиск по описанию или категориям, требуется просто ввести запрос в терминал
3.  **Траты по дням недели** выводит JSON-ответ, который содержит средние траты на протяжении трех месяцев от указанной даты по дням недели

### Запуск проекта:
Для запуска проекта выполните
    ```
    python main.py
    ```
### Тестирование:
Для тестирования программы запустите в терминале следующую команду:
    ```
    pytest
    ```

Для просмотра покрытия тестов запустите в терминале следующую команду:
    ```
    poetry run pytest --cov
    ```
#### Нововведения:
Фикс всех модулей, а также тестирование при помощи библиотеки pytest
